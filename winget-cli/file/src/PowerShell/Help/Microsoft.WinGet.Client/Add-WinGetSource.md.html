     10 # Add-WinGetSource
     11 
     12 ## SYNOPSIS
     13 Adds a new source.
     14 
     15 ## SYNTAX
     16 
     17 ```
     18 Add-WinGetSource -Name <String> -Argument <String> [-Type <String>] [-TrustLevel {Default | None | Trusted}] [-Explicit] [<CommonParameters>]
     19 ```
     20 
     21 ## DESCRIPTION
     22 
     23 Adds a new source. A source provides the data for you to discover and install packages. Only add a
     24 new source if you trust it as a secure location. This command must be executed with administrator permissions.
     25 
     26 ## EXAMPLES
     27 
     28 ### Example 1: Add new REST source named mysource
     29 
     30 ```powershell
     31 Add-WinGetSource -Name mysource -Argument https://contoso.com/ -Type Microsoft.Rest
     32 ```
     33 
     34 This example adds a new REST source to WinGet named `mysource` with the root URL
     35 `https://contoso.com/`. The source must respond with the WinGet REST source API.
     36
