     10 # Assert-WinGetPackageManager
     11 
     12 ## SYNOPSIS
     13 Verifies that WinGet is installed properly.
     14 
     15 ## SYNTAX
     16 
     17 ### IntegrityVersionSet (Default)
     18 
     19 ```
     20 Assert-WinGetPackageManager [-Version <String>] [<CommonParameters>]
     21 ```
     22 
     23 ### IntegrityLatestSet
     24 
     25 ```
     26 Assert-WinGetPackageManager [-Latest] [-IncludePrerelease] [<CommonParameters>]
     27 ```
     28 
     29 ## DESCRIPTION
     30 
     31 Verifies that WinGet is installed properly.
     32 
     33 > [!NOTE]
     34 > The cmdlet doesn't ensure that the latest version of WinGet is installed. It just verifies that
     35 > the installed version of Winget is supported by installed version of the Microsoft.WinGet.Client
     36 > module.
     37 
     38 ## EXAMPLES
     39 
     40 ### Example 1: Default usage
     41 
     42 ```powershell
     43 Assert-WinGetPackageManager
     44 ```
     45 
     46 If the current version of WinGet is installed correctly, the command returns without error.
     47 
     48 ### Example 2: Check if latest stable version is installed
     49 
     50 ```powershell
     51 Assert-WinGetPackageManager -Latest
     52 ```
     53 
     54 If the latest version of WinGet is compatible with the installed Microsoft.WinGet.Client module, the
     55 command returns without error.
     56 
     57 ### Example 3: Check if latest preview version is installed
     58 
     59 ```powershell
     60 Assert-WinGetPackageManager -IncludePreRelease
     61 ```
     62 
     63 If the prerelease version of WinGet is compatible with the installed Microsoft.WinGet.Client module,
     64 the command returns without error.
     65 
     66 ### Example 4: Check if specific version is installed
     67 
     68 ```powershell
     69 Assert-WinGetPackageManager -Version v1.8.1911
     70 ```
     71 
     72 If the specified version of WinGet is compatible with the installed Microsoft.WinGet.Client module,
     73 the command returns without error.
     74
