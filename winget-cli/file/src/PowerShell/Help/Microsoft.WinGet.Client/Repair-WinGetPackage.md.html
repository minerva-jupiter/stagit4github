      9 # Repair-WinGetPackage
     10 
     11 ## SYNOPSIS
     12 Repairs a WinGet Package.
     13 
     14 ## SYNTAX
     15 
     16 ### FoundSet (Default)
     17 ```
     18 Repair-WinGetPackage [-Mode <PSPackageRepairMode>] [-Log <String>] [-Version <String>] [-Id <String>]
     19  [-Name <String>] [-Moniker <String>] [-Source <String>] [[-Query] <String[]>]
     20  [-MatchOption <PSPackageFieldMatchOption>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
     21  [<CommonParameters>]
     22 ```
     23 
     24 ### GivenSet
     25 ```
     26 Repair-WinGetPackage [-Mode <PSPackageRepairMode>] [-Log <String>] [[-PSCatalogPackage] <PSCatalogPackage>]
     27  [-Version <String>] [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
     28 ```
     29 
     30 ## DESCRIPTION
     31 This command repairs a WinGet package from your computer, provided the package includes repair support.
     32 The command includes parameters to specify values used to search for installed packages. By default,
     33 all string-based searches are case-insensitive substring searches. Wildcards are not supported.
     34 You can change the search behavior using the **MatchOption** parameter.
     35 
     36 > **Note: Not all packages support repair.**
     37 
     38 ## EXAMPLES
     39 
     40 ### Example 1: Repair a package using a query
     41 ```powershell
     42 Repair-WinGetPackage -Query "Microsoft.GDK.2406"
     43 ```
     44 This example  shows how to repair a package using a query. The **Query** parameter is positional, so you 
     45 don't need to include the parameter name before the query string.
     46 
     47 ### Example 3 : Repair a package by Id
     48 ```powershell
     49 Repair-WinGetPackage -Id "Microsoft.GDK.2406"
     50 ```
     51 This example shows how to repair a package by specifying the package identifier.
     52 
     53 If the package identifier is available from more than one source, you must provide additional search
     54 criteria to select a specific instance of the package.
     55 
     56 ### Example 3: Repair a package using by Name
     57 ```powershell
     58 Repair-WinGetPackage -Name "Microsoft Game Development Kit - 240602 (June 2024 Update 2)"
     59 ```
     60 This example shows how to repair a package using the package name. 
     61 
     62 > **Note: Please note that the examples mentioned above are mainly reference examples for the repair cmdlet and may not be operational as is, since many installers don't support repair as a standard functionality. For the Microsoft.GDK.2406 example, the assumption is that Microsoft.GDK.2406 supports repair capability and the author of the installer has provided the necessary repair context/switches in the Package Manifest in the Package Source referenced by the WinGet Client.**
