      9 # Submit packages to Windows Package Manager
     10 
     11 ## Independent Software Vendor (ISV) or Publisher
     12 
     13 If you are an ISV or Publisher, you can use Windows Package Manager as a distribution channel for software packages containing your applications. Windows Package Manager currently supports installers in the following formats: MSIX, MSI, and EXE.
     14 
     15 To submit software packages to Windows Package Manager, follow these steps:
     16 
     17 1. [Create a package manifest that provides information about your application](manifest.md). Manifests are YAML files that follow the Windows Package Manager schema.
     18 2. [Submit your manifest to the Windows Package Manager repository](repository.md). This is an open source repository on GitHub that contains a collection of manifests that the **winget** tool can access.
     19 
     20 ## Community Member
     21 
     22 If you are a GitHub community member, you may also submit packages to Windows Package Manager following the steps above.
     23 
     24 Optionally, you may also request help to have a package added to the [community repository](https://github.com/microsoft/winget-pkgs). To do so, create a new [Package Request/Submission](https://github.com/microsoft/winget-pkgs/issues/new/choose) Issue.
