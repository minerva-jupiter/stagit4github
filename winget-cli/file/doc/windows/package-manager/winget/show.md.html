      9 # show command (winget)
     10 
     11 The **show** command of the [winget](index.md) tool displays details for the specified application, including details on the source of the application as well as the metadata associated with the application.
     12 
     13 The **show** command only shows metadata that was submitted with the application. If the submitted application excludes some metadata, then the data will not be displayed.
     14 
     15 ## Usage
     16 
     17 `winget show [[-q] <query>] [<options>]`
     18 
     19 The following command aliases are available: \
     20 `view`
     21 
     22 ![show command](images/show.png)
     23 
     24 ## Arguments
     25 
     26 The following arguments are available.
     27 
     28 | Argument  | Description |
     29 |--------------|-------------|
     30 | **-q, --query** |  The query used to search for an application. |
     31 
     32 ## Options
     33 
     34 The following options are available.
     35 
     36 | Option  | Description |
     37 |--------------|-------------|
     38 | **-m,--manifest** | The path to the manifest of the application to install. |
     39 | **--id**         |  Filter results by ID. |
     40 | **--name**   |      Filter results by name. |
     41 | **--moniker**   |  Filter results by application moniker. |
     42 | **-v,--version** |  Use the specified version. The default is the latest version. |
     43 | **-s,--source** |   Find the application using the specified [source](source.md). |
     44 | **-e,--exact**     | Find the application using exact match. |
     45 | **--versions**    | Show available versions of the application. |
     46 | **--scope** | Select install scope (user or machine). |
     47 | **-a, --architecture** | Select the architecture. |
     48 | **--installer-type** | Select the installer type. |
     49 | **--locale** | Locale to use (BCP47 format). |
     50 | **--header** | Optional Windows-Package-Manager REST source HTTP header. |
     51 | **--accept-source-agreements** | Accept all source agreements during source operations. |
     52 | **-?, --help** | Gets additional help on this command. |
     53 | **--wait** | Prompts the user to press any key before exiting. |
     54 | **--logs, --open-logs** | Open the default logs location. |
     55 | **--verbose, --verbose-logs** | Enables verbose logging for winget. |
     56 | **--disable-interactivity** | Disable interactive prompts. |
     57 
     58 ## Multiple selections
     59 
     60 If the query provided to **winget** does not result in a single application, then **winget** will display the results of the search. This will provide you with the additional data necessary to refine the search.
     61 
     62 ## Results of show
     63 
     64 If a single application is detected, the following data will be displayed.
     65 
     66 ### Metadata
     67 
     68 | Value  | Description |
     69 |--------------|-------------|
     70 | **Version** | Version of the application. |
     71 | **Publisher** | Publisher of the application. |
     72 | **Moniker** | AppMoniker of the application. |
     73 | **Description** | Description of the application. |
     74 | **Homepage**  | Homepage of the application. |
     75 | **License**  | License of the application. |
     76 | **LicenseUrl** | The URL to the license file of the application. |
     77 
     78 ### Installer details
     79 
     80 | Value  | Description |
     81 |--------------|-------------|
     82 | **Type**  | The type of installer. |
     83 | **Download Url** | The Url of the installer. |
     84 | **SHA256** | The Sha-256 of the installer.  |
