      9 # list command (winget)
     10 
     11 The **list** command of the [winget](index.md) tool displays a list of the applications currently installed on your computer.  The list command will show apps that were installed through the Windows Package Manager as well as apps that were installed by other means.
     12 
     13 In addition, the **list** command will also display if an update is available for an app, and you can use the [**upgrade**](upgrade.md) command to update the app.
     14 
     15 The **list** command also supports filters which can be used to limit your list query.
     16 
     17 ## Usage
     18 
     19 `winget list [[-q] <query>] [<options>]`
     20 
     21 The following command aliases are available: \
     22 `ls`
     23 
     24 ![list help command](images/list.png)
     25 
     26 ## Arguments
     27 
     28 The following arguments are available.
     29 
     30 | Argument | Description |
     31 |-------------|-------------|
     32 | **-q,--query** | The query used to search for an app. |
     33 
     34 ## Options
     35 
     36 The options allow you to customize the list experience to meet your needs.
     37 | Option | Description |
     38 |--------|-------------|
     39 | **--id** | Limits the list to the ID of the application. |
     40 | **--name** | Limits the list to the name of the application. |
     41 | **--moniker** | Limits the list to the moniker listed for the application. |
     42 | **-s, --source** | Restricts the list to the source name provided. Must be followed by the source name. |
     43 | **--tag** | Filters results by tags. |
     44 | **--command** | Filters results by command specified by the application. |
     45 | **-n, --count** | Limits the number of apps displayed in one query. |
     46 | **-e, --exact** | Uses the exact string in the list query, including checking for case-sensitivity. It will not use the default behavior of a substring. |
     47 | **--scope** | Select installed package scope filter (user or machine). |
     48 | **--header** | Optional Windows-Package-Manager REST source HTTP header. |
     49 | **--accept-source-agreements** | Accept all source agreements during source operations. |
     50 | **--upgrade-available** | Lists only packages which have an upgrade available. |
     51 | **-u,--unknown,--include-unknown** | List packages even if their current version cannot be determined. Can only be used with the --upgrade-available argument. |
     52 | **--pinned,--include-pinned** | List packages even if they have a pin that prevents upgrade. Can only be used with the --upgrade-available argument. |
     53 | **-?,--help** | Get additional help on this command. |
     54 | **--wait** | Prompts the user to press any key before exiting. |
     55 | **--logs,--open-logs** | Open the default logs location. |
     56 | **--verbose,--verbose-logs** | Enables verbose logging for winget. |
     57 | **--disable-interactivity** | Disable interactive prompts. |

     73 ## List with Update
     74 
     75 As stated above, the **list** command allows you to see what apps you have installed that have updates available.
     76 
     77 In the image below, you will notice the current version of **Google Chrome** has an update available.
     78 
     79 ![list update command](images/list-update.png)
     80 
     81 The **list** command will show not only the update version available, but the source that the update is available from.
