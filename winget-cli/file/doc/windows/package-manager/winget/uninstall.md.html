      9 # uninstall command (winget)
     10 
     11 The **uninstall** command of the [winget](index.md) tool uninstalls the specified application.
     12 
     13 The **uninstall** command requires that you specify the exact string to uninstall. If there is any ambiguity, you will be prompted to further filter the **uninstall** command to an exact application.
     14 
     15 ## Usage
     16 
     17 `winget uninstall [[-q] <query>...] [<options>]`
     18 
     19 The following command aliases are available: \
     20 `remove` \
     21 `rm`
     22 
     23 ![uninstall command](images/uninstall.png)
     24 
     25 ## Arguments
     26 
     27 The following arguments are available.
     28 
     29 | Argument | Description |
     30 |-------------|-------------|
     31 | **-q,--query**  |  The query used to search for an app. |
     32 
     33 ## Options
     34 
     35 The options allow you to customize the uninstall experience to meet your needs.
     36 
     37 | Option | Description |
     38 |--------|-------------|
     39 | **-m, --manifest** | Must be followed by the path to the manifest (YAML) file. You can use the manifest to run the uninstall experience from a [local YAML file](#local-uninstall). |
     40 | **--id** | Limits the uninstall to the ID of the application. |
     41 | **--name** | Limits the search to the name of the application. |
     42 | **--moniker** | Limits the search to the moniker listed for the application. |
     43 | **-v, --version** | Enables you to specify an exact version to uninstall. If not specified, the latest will uninstall the highest versioned application. |
     44 | **-s, --source** | Restricts the search to the source name provided. Must be followed by the source name. |
     45 | **-e, --exact** | Uses the exact string in the query, including checking for case-sensitivity. It will not use the default behavior of a substring. |
     46 | **-i, --interactive** | Runs the uninstaller in interactive mode. The default experience shows uninstaller progress. |
     47 | **-h, --silent** | Runs the uninstaller in silent mode. This suppresses all UI. The default experience shows uninstaller progress. |
     48 | **-o, --log** | Directs the logging to a log file. You must provide a path to a file that you have the write rights to. |
     49 | **--product-code** | Filters using the product code. |
     50 | **--scope** | Select installed package scope filter (user or machine). |
     51 | **--force** | Directly run the command and continue with non-security-related issues. |
     52 | **--purge** | Deletes all files and directories in the package directory (portable). |
     53 | **--preserve** | Retains all files and directories created by the package (portable). |
     54 | **--header** | Optional Windows-Package-Manager REST source HTTP header. |
     55 | **--accept-source-agreements** | Accept all source agreements during source operations. |
     56 | **-?, --help** | Get additional help on this command. |
     57 | **--wait** | Prompts the user to press any key before exiting. |
     58 | **--logs, --open-logs** | Open the default logs location. |
     59 | **--verbose, --verbose-logs** | Enables verbose logging for winget. |
     60 | **--disable-interactivity** | Disable interactive prompts. |
     61 
     62 Once you have successfully identified the application intended to uninstall, winget will execute the uninstall command.  In the example below, the **name** 'orca' and the **id** was passed in.
     63 
     64 ![uninstall command](images/uninstall-execute.png)
     65 
     66 
     67 ### Example queries
     68 
     69 The following example uninstalls a specific version of an application.
     70 
     71 ```CMD
     72 winget uninstall --name powertoys --version 0.15.2
     73 ```
     74 
     75 The following example uninstalls an application using its ID.
     76 
     77 ```CMD
     78 winget uninstall --id "{24559D0F-481C-F3BE-8DD0-D908923A38F8}"
     79 ```
     80 
     81 ## Multiple selections
     82 
     83 If the query provided to **winget** does not result in a single application to uninstall, then **winget** will display multiple results. You can then use additional filters to refine the search for a correct application.
     84 
     85 ![uninstall command](images/uninstall-multiple.png)

     87 ## Uninstalling apps not installed with Windows Package Manager
     88 As mentioned in [**list**](list.md), the **winget list** command will display more than just apps installed with the **winget**.  Therefore you can use these commands to quickly and easily remove apps from your PC.
     89
