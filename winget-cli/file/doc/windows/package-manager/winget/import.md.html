      9 # import command (winget)
     10 
     11 The **import** command of the [winget](index.md) tool imports a JSON file of apps to install.  The **import** command combined with the [**export**](export.md) command allows you to batch install applications on your PC.
     12 
     13 The **import** command is often used to share your developer environment or build up your PC image with your favorite apps.
     14 
     15 ## Usage
     16 
     17 `winget import [-i] <import-file> [<options>]`
     18 
     19 ![import](images/import.png)
     20 
     21 ## Arguments
     22 
     23 The following arguments are available.
     24 | Argument    | Description |
     25 |-------------|-------------|
     26 | **-i, --import-file** | JSON file describing the packages to install
     27 
     28 ## Options
     29 
     30 The options allow you to customize the import experience to meet your needs.
     31 
     32 | Option | Description |
     33 |-------------|-------------|
     34 | **--ignore-unavailable** | Suppresses errors if the app requested is unavailable |
     35 | **--ignore-versions** | Ignores versions specified in the JSON file and installs the latest available version |
     36 | **--no-upgrade** | Skips upgrade if an installed version already exists |
     37 | **--accept-package-agreements** | Accept all license agreements for packages |
     38 | **--accept-source-agreements** | Accept all source agreements during source operations |
     39 | **-?, --help** | Shows help about the selected command |
     40 | **--wait** | Prompts the user to press any key before exiting |
     41 | **--logs, --open-logs** | Open the default logs location |
     42 | **--verbose, --verbose-logs** | Enables verbose logging for winget |
     43 | **--disable-interactivity** | Disable interactive prompts |
     44 
     45 ## JSON Schema
     46 The driving force behind the **import** command is the JSON file.  You can see the [schema for the JSON file](https://aka.ms/winget-packages.schema.1.0.json).
     47 
     48 The JSON file includes the following hierarchy:
     49 | Entry      | Description |
     50 |-------------|-------------|
     51 | **Sources**  |  The sources application manifests come from.  |
     52 | **Packages**  |  The collection of packages to install.  |
     53 | **PackageIdentifier**  |  The Windows Package Manager package identifier used to specify the package.  |
     54 | **Version**  |  [optional] The specific version of the package to install.  |
     55 
     56 ## Importing files
     57 
     58 When the Windows Package Manager imports the JSON file, it attempts to install the specified applications in a serial fashion. If the application is not available or the application is already installed, it will notify the user of that case.
     59 
     60 ![import](images/import-command.png)
     61 
     62 You will notice in the example above, **Microsoft.VisualStudioCode** and **JanDeDobbeleer.OhMyPosh** were already installed. Therefore the import command skipped the installation.
