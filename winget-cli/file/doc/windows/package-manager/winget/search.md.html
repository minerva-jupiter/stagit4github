      9 # search command (winget)
     10 
     11 The **search** command of the [winget](index.md) tool queries the sources for available applications that can be installed.
     12 
     13 The **search** command can show all applications available, or it can be filtered down to a specific application. The **search** command is used typically to identify the string to use to install a specific application.
     14 
     15 ## Usage
     16 
     17 `winget search [[-q] <query>] [<options>]`
     18 
     19 The following command aliases are available: \
     20 `find`
     21 
     22 ![Screenshot of the Windows Power Shell window displaying the results of the winget search.](images/search.png)
     23 
     24 ## Arguments
     25 
     26 The following arguments are available.
     27 
     28 | Argument  | Description |
     29  --------------|-------------|
     30 | **-q, --query** |  The query used to search for an app. |
     31 
     32 ## Show all
     33 
     34 If the search command includes no filters or options, it will display all available applications in the default source. You can also search for all applications in another source if you pass in just the **source** option.
     35 
     36 ## Search strings
     37 
     38 Search strings can be filtered with the following options.
     39 
     40 | Option  | Description |
     41  --------------|-------------|
     42 | **--id** | Limits the search to the ID of the application. The ID includes the publisher and the application name. |
     43 | **--name** | Limits the search to the name of the application. |
     44 | **--moniker** | Limits the search to the moniker specified. |
     45 | **--tag** | Limits the search to the tags listed for the application. |
     46 | **--cmd, --command** | Limits the search to the commands listed for the application. |
     47 | **-s, --source** | Find package using the specified source. |
     48 | **-n, --count** | Show no more than specified number of results (between 1 and 1000). |
     49 | **-e, --exact** | Find package using exact match. |
     50 | **--header** | Optional Windows-Package-Manager REST source HTTP header. |
     51 | **--accept-source-agreements** | Accept all source agreements during source operations. |
     52 | **--versions** | Show available versions of the package. |
     53 | **-?, --help** | Gets additional help on this command. |
     54 | **--wait** | Prompts the user to press any key before exiting. |
     55 | **--logs, --open-logs** | Open the default logs location. |
     56 | **--verbose, --verbose-logs** | Enables verbose logging for winget. |
     57 | **--disable-interactivity** | Disable interactive prompts. |
     58 
     59 The string will be treated as a substring. The search by default is also case-insensitive. For example, `winget search micro` could return the following:
     60 
     61 * Microsoft
     62 * Microscope
     63 * MyMicro
     64 
     65 ## Search options
     66 
     67 The search commands supports a number of options or filters to help limit the results.
     68 
     69 | Option  | Description |
     70  --------------|-------------|
     71 | **-e, --exact** | Uses the exact string in the query, including checking for case-sensitivity. It will not use the default behavior of a substring. |
     72 | **-n, --count** | Restricts the output of the display to the specified count. |
     73 | **-s, --source** | Restricts the search to the specified [source](source.md) name. |
