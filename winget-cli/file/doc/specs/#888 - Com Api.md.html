      1 # 1. Background
      2 
      3 The Windows Package Manager currently exposes a command line interface to search for packages,
      4 install them, view progress, and more. This API is designed to provide another way for callers to
      5 make use of that functionality. The API will be preferred by callers that want to receive progress
      6 and completion events, and UWP packages that do not have permission to launch command line processes.
      7 The goal for this api is to provide the full set of install functionality possible using the Windows
      8 Package Manager command line. The command line is documented at
      9 https://docs.microsoft.com/windows/package-manager/winget/
     10 
     11 # 2. Description
     12 
     13 Windows Package Manager is a package manager for windows applications. It comes with a predefined
     14 repository of applications and users can add new repositories using the winget command line. This
     15 API allows packaged apps with the packageManagement capability and other higher privilege processes
     16 to start, manage, and monitor installation of packages that are listed in Windows Package Manager
     17 repositories.
     18

     48 ## 3.2. Search
     49 
     50 The api can be used to search for packages in a catalog known to Windows Package Manager. This can
     51 be used to get availability information or start an install.
     52 
     53 ```c++ (C++ish pseudocode)
     54 
     55     // Sample of using synchronous methods on background thread.
     56     CatalogPackage MainPage::FindPackageOnBackgroundThread()
     57     {
     58         PackageManager packageManager = CreatePackageManager();
     59         PackageCatalogReference catalogRef{
     60             packageManager.GetPredefinedPackageCatalog(PredefinedPackageCatalog::OpenWindowsCatalog) };
     61         ConnectResult connectResult = catalogRef.Connect();
     62         if (connectResult.Status() != ConnectResultStatus::Ok)
     63         {
     64             return nullptr;
     65         }
     66         PackageCatalog catalog = connectResult.PackageCatalog();
     67 
     68         FindPackagesOptions findPackagesOptions = CreateFindPackagesOptions();
     69         PackageMatchFilter filter = CreatePackageMatchFilter();
     70         filter.Field(PackageMatchField::Id);
     71         filter.Option(PackageFieldMatchOption::Equals);
     72         filter.Value(m_installAppId);
     73         findPackagesOptions.Filters().Append(filter);
     74         // We've already switched to a background thread, so do everything synchronously.
     75         FindPackagesResult findPackagesResult{ catalog.FindPackages(findPackagesOptions) };
     76 
     77         winrt::IVectorView<MatchResult> matches = findPackagesResult.Matches();
     78         if (matches.Size() == 0)
     79         {
     80             return nullptr;
     81         }
     82         return matches.GetAt(0).CatalogPackage();
     83     }
     84 
     85     // Sample of using async methods.
     86     IAsyncOperation<CatalogPackage> MainPage::FindPackageInCatalogAsync(PackageCatalog catalog,
     87             std::wstring packageId)
     88     {
     89         FindPackagesOptions findPackagesOptions = CreateFindPackagesOptions();
     90         PackageMatchFilter filter = CreatePackageMatchFilter();
     91         filter.Field(PackageMatchField::Id);
     92         filter.Option(PackageFieldMatchOption::Equals);
     93         filter.Value(packageId);
     94         findPackagesOptions.Filters().Append(filter);
     95         FindPackagesResult findPackagesResult{ co_await catalog.FindPackagesAsync(findPackagesOptions) };
     96 
     97         winrt::IVectorView<MatchResult> matches = findPackagesResult.Matches();
     98         if (matches.Size() == 0)
     99         {
    100             co_return nullptr;
    101         }
    102         co_return matches.GetAt(0).CatalogPackage();
    103     }

    106     {

    133      IAsyncAction UpdateUIProgress(
    134         InstallProgress progress,
    135         winrt::Windows::UI::Xaml::Controls::ProgressBar progressBar,
    136         winrt::Windows::UI::Xaml::Controls::TextBlock statusText)
    137     {
    138         co_await winrt::resume_foreground(progressBar.Dispatcher());
    139         progressBar.Value(progress.DownloadProgress*100);
    140 
    141         std::wstring downloadText{ L"Downloading. " };
    142         switch (progress.State)
    143         {
    144         case PackageInstallProgressState::Queued:
    145             statusText.Text(L"Queued");
    146             break;
    147         case PackageInstallProgressState::Downloading:
    148             downloadText += std::to_wstring(progress.BytesDownloaded) + L" bytes of " + std::to_wstring(progress.BytesRequired);
    149             statusText.Text(downloadText);
    150             break;
    151         case PackageInstallProgressState::Installing:
    152             statusText.Text(L"Installing");
    153             progressBar.IsIndeterminate(true);
    154             break;
    155         case PackageInstallProgressState::PostInstall:
    156             statusText.Text(L"Finishing install");
    157             break;
    158         case PackageInstallProgressState::Finished:
    159             statusText.Text(L"Finished install.");
    160             progressBar.IsIndeterminate(false);
    161             break;
    162         default:
    163             statusText.Text(L"");
    164         }
    165         co_return;
    166     }
    167 
    168     // This method is called from a background thread.
    169     IAsyncAction UpdateUIForInstall(
    170         IAsyncOperationWithProgress<InstallResult, InstallProgress> installPackageOperation,
    171         winrt::Windows::UI::Xaml::Controls::Button installButton,
    172         winrt::Windows::UI::Xaml::Controls::Button cancelButton,
    173         winrt::Windows::UI::Xaml::Controls::ProgressBar progressBar,
    174         winrt::Windows::UI::Xaml::Controls::TextBlock statusText)
    175     {
    176         if (installPackageOperation)
    177         {
    178 
    179             installPackageOperation.Progress([=](
    180                 IAsyncOperationWithProgress<InstallResult, InstallProgress> const& /* sender */,
    181                 InstallProgress const& progress)
    182                 {
    183                     UpdateUIProgress(progressBar, statusText, 50, stateStr).get();
    184                 });
    185 
    186 
    187             winrt::hresult installOperationHr = S_OK;
    188             std::wstring errorMessage{ L"Unknown Error" };
    189             InstallResult installResult{ nullptr };
    190             try
    191             {
    192                 installResult = co_await installPackageOperation;
    193             }
    194             catch (hresult_canceled const&)
    195             {
    196                 errorMessage = L"Cancelled";
    197                 OutputDebugString(L"Operation was cancelled");
    198             }
    199             catch (...)
    200             {
    201                 // Operation failed
    202                 // Example: HRESULT_FROM_WIN32(ERROR_DISK_FULL).
    203                 installOperationHr = winrt::to_hresult();
    204                 // Example: "There is not enough space on the disk."
    205                 errorMessage = winrt::to_message();
    206                 OutputDebugString(L"Operation failed");
    207             }
    208 
    209             // Switch back to ui thread context.
    210             co_await winrt::resume_foreground(progressBar.Dispatcher());
    211 
    212             cancelButton.IsEnabled(false);
    213             installButton.IsEnabled(true);
    214             progressBar.IsIndeterminate(false);
    215 
    216             if (installPackageOperation.Status() == AsyncStatus::Canceled)
    217             {
    218                 installButton.Content(box_value(L"Retry"));
    219                 statusText.Text(L"Install cancelled.");
    220             }
    221             if (installPackageOperation.Status() == AsyncStatus::Error || installResult == nullptr)
    222             {
    223                 installButton.Content(box_value(L"Retry"));
    224                 statusText.Text(errorMessage);
    225             }
    226             else if (installResult.RebootRequired())
    227             {
    228                 installButton.Content(box_value(L"Install"));
    229                 statusText.Text(L"Reboot to finish installation.");
    230             }
    231             else if (installResult.Status() == InstallResultStatus::Ok)
    232             {
    233                 installButton.Content(box_value(L"Install"));
    234                 statusText.Text(L"Finished.");
    235             }
    236             else
    237             {
    238                 installButton.Content(box_value(L"Install"));
    239                 statusText.Text(L"Install failed.");
    240             }
    241         }
    242     }

    244     IAsyncAction MainPage::StartInstall(
    245         winrt::Windows::UI::Xaml::Controls::Button installButton,
    246         winrt::Windows::UI::Xaml::Controls::Button cancelButton,
    247         winrt::Windows::UI::Xaml::Controls::ProgressBar progressBar,
    248         winrt::Windows::UI::Xaml::Controls::TextBlock statusText)
    249     {
    250         installButton.IsEnabled(false);
    251         cancelButton.IsEnabled(true);
    252 
    253         co_await winrt::resume_background();
    254 
    255         PackageManager packageManager = CreatePackageManager();
    256         PackageCatalogReference catalogRef{
    257             packageManager.GetPredefinedPackageCatalog(PredefinedPackageCatalog::OpenWindowsCatalog) };
    258         ConnectResult connectResult = catalogRef.Connect();
    259         if (connectResult.Status() != ConnectResultStatus::Ok)
    260         {
    261             co_await winrt::resume_foreground(progressBar.Dispatcher());
    262             statusText.Text(L"Connecting to catalog failed.");
    263             co_return;
    264         }
    265         PackageCatalog catalog = connectResult.PackageCatalog();
    266 
    267         FindPackagesResult findPackagesResult{ FindPackageOnBackgroundThread(catalog, m_installAppId) };
    268 
    269         winrt::IVectorView<MatchResult> matches = findPackagesResult.Matches();
    270         if (matches.Size() > 0)
    271         {
    272             m_installPackageOperation = InstallPackage(matches.GetAt(0).CatalogPackage());
    273             UpdateUIForInstall(m_installPackageOperation, installButton, cancelButton, progressBar, statusText);
    274         }
    275         else
    276         {
    277             co_await winrt::resume_foreground(progressBar.Dispatcher());
    278             statusText.Text(L"Could not find package.");
    279             co_return;
    280         }
    281     }

    298 ## 3.5. Open a catalog by name
    299 
    300 Open a catalog known to the caller. There is no way to use the api to add a catalog, that must be done
    301 on the command line.
    302 
    303 ```c++ (C++ish pseudocode)
    304     IAsyncOperation<PackageCatalog> MainPage::FindSourceAsync(std::wstring packageSource)
    305     {
    306         PackageManager packageManager = CreatePackageManager();
    307         PackageCatalogReference catalogRef{ packageManager.GetPackageCatalogByName(packageSource) };
    308         if (catalogRef)
    309         {
    310             ConnectResult connectResult{ co_await catalogRef.ConnectAsync() };
    311             // PackageCatalog will be null if connectResult.ErrorCode() is a failure
    312             PackageCatalog catalog = connectResult.PackageCatalog();
    313             co_return catalog;
    314         }
    315     }
    316 ```

    318 # 4 Remarks
    319 
    320 Notes have been added inline throughout the api details.
    321 
    322 
    323 For this api there are multiple similar apis that are
    324 relevant with regard to naming and consistency. There is the Windows Package Manager command line which uses
    325 "source" to describe the various repositories that can host packages and "search" to describe looking up an app.
    326 https://docs.microsoft.com/windows/package-manager/winget/
    327 There is the Windows::ApplicationModel::PackageCatalog which exists as a Windows API for installing packages
    328 and monitoring their installation progress.
    329 https://docs.microsoft.com/uwp/api/windows.applicationmodel.packagecatalog?view=winrt-19041
    330 And there is Windows.Management.Deployment.PackageManager which allows packages with the packageManagement
    331 capability to install msix apps and uses "Find" to describe looking up an app
    332 https://docs.microsoft.com/uwp/api/windows.management.deployment.packagemanager?view=winrt-19041
    333 
    334 This API has aligned with those Windows APIs in using \*Catalog and Find.
