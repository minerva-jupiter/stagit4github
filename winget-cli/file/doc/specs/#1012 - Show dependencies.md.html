      8 # Show dependencies
      9 
     10 For [#1012](https://github.com/microsoft/winget-cli/issues/1012)
     11 
     12 ## Abstract
     13 Several packages require other packages as dependencies. The Windows Package Manager should be able to support declared dependencies and, as a first step to manage them, inform the user about any required ones.
     14 
     15 ## Solution Design
     16 The Windows Package Manager should be able to report package dependency information for each of the four different types of dependencies declared in the [v1.0 manifest schemas](https://github.com/microsoft/winget-cli/blob/master/schemas/JSON/manifests/v1.0.0/).
     17 
     18 * Windows Features
     19 * Windows Libraries
     20 * Package Dependencies (same source)
     21 * External Dependencies
     22 
     23 Only dependencies declared in the manifest/installer will be shown, not the entire dependency graph.
     24

    126 ## Capabilities
    127 It's only an informational feature, will not check if the dependency is a valid one, nor if the source is available.
    128 If a dependency is declared more than once (for example when gathering all dependencies in an import) it will only show the highest minimum version needed.
    129 
    130 Keep in mind dependencies can be declared on the root manifest and on each of the installers. If they happen to be declared in both, installer's dependencies will override those of the manifest. With the manifest's dependencies working as a default whenever installer's dependencies are not declared.
    131 
    132 ## Future considerations
    133 It may be able to enable/disable this feature using extra options for the command.
