      8 # Enhancements to List Command
      9 
     10 For [#1155](https://github.com/microsoft/winget-cli/issues/1155).
     11 
     12 ## Abstract
     13 
     14 The `winget list` command was designed to display all packages installed on a users Windows 10 machine in Add / Remove Programs (ARP). The command would also show which Apps with possible upgrades were available from sources configured in the Windows Package Manager. This specification proposes enhancements to the output provided by the list command.
     15 
     16 The first enhancement is adding the values for "Available" and "Source" for every package in configured sources rather that just packages with upgrades available.
     17 
     18 The second enhancement is reducing the set of packages to the source specified when the source is passed as an argument to the list command.
     19 
     20 The third enhancement is adding an argument to provide the list of Apps with no matching package in configured sources.
     21 
     22 ## Inspiration
     23 
     24 Several suggestions have been made on how to improve user experience. Recently, many users have been attempting to identify Apps on their system with no corresponding package in the Microsoft Community Repository.
     25 
     26 ## Solution Design
     27 
     28 Modify the output behavior for `winget list` to display available version from any source. When a package is available via more than once source, the first configured source should be displayed.
     29 
     30 >Note: Users will be able to see if packages are available from individual sources by specifying the source as an argument to the list command.
     31 
     32 Modify the output behavior for `winget list -s <source>` to display only packages available from the specified source.
     33 
     34 Add a new argument `-u, --unavailable`  to the list command to display Apps installed in ARP not matching any configured source.
     35 
     36 ## UI/UX Design
     37 
     38 The UI would remain consistent with the current tabular output.
