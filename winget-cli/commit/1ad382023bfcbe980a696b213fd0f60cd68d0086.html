WinGetDownload E_ACCESSDENIED (#4518)

Fix issue when calling WinGetDownload from Az Functions.

It is most likely caused by an attempt to create the directory while
reading the admin settings. Instead of failing, catch the exception and
use the default settings.

If we ever read more settings from WinGetUtil a more robust solution is
required.
