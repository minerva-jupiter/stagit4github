Fix a potential infinite loop due to file read errors during hashing (#1175)

The `std::istream` was not handled properly here, as only `eof` determined the loop termination, when any of the state bits should have.  Now requires `good` and additionally lets `bad` throw exceptions directly, while throwing our own generic exception if `fail` is set without `eof`.
