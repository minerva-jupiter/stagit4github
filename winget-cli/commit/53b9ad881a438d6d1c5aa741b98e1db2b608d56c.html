Name an Publisher correlation in CompositeSource (#955)

This change leverages the normalized name and publisher to increase the number of packages that can be matched.  It also reworks the way the the correlation occurs internally, albeit only slightly.

All operations that rely on this data should now work better; this includes `import`, `list`, `upgrade`, and `uninstall`.
