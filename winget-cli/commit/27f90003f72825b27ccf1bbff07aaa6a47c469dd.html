include:

- Updates to WinGetCLIPackage manifest for Repair COM API GUIDs.
- Changes to Microsoft.Management.Deployment.InProc to support E2E
testing of Repair COM API interops.

Add Repair-WinGetPackage powershell cmdlet to Microsoft.WinGet.Client
- Introduced a new cmdlet `Repair-WinGetPackage` to the
Microsoft.WinGet.Client PowerShell module
