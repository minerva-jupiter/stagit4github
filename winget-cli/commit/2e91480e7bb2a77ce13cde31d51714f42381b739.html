Store configuration status and enable remote watch events (#4647)

## Change
This change stores ongoing status information during configuration
application in the database. This data is then retrievable via the
existing API surface from a set retrieved from
`GetConfigurationHistory`. The data includes: configuration set state,
configuration set apply start/stop times, configuration unit state, and
configuration unit results.

In addition, the existing events on the `ConfigurationProcessor` and
`ConfigurationSet` are implemented to send data when appropriate. This
works across processes, using named events to indicate changes and the
database to carry the actual data.

`winget configure list` is updated to expose this information, for
example:
