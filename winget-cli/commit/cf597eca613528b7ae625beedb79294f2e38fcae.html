Make Ignore Warnings suppress the output level entirely (#4221)

<!-- To check a checkbox place an "x" between the brackets. e.g: [x] -->

- [x] I have signed the [Contributor License
Agreement](https://cla.opensource.microsoft.com/microsoft/winget-pkgs).
- [x] This pull request is related to an issue.
  * Resolves #4213 
  * Closes #4214

Instead of handling each case individually, this PR makes the
`--ignore-warnings` a common argument and suppresses all output from
`context.Reporter.Warn()`. Support is added for enabling or disabling
each reporter level individually.
