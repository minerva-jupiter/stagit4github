Configure validate command (#3441)

Implements the `configure validate` command that will help discover potential issues with a configuration file.  More validation can be added in the future, but currently the flow is:
1. Open the file and report on any YAML / configuration schema errors
2. Determine if there are any semantic errors in the configuration (duplicate identifiers, missing dependencies, cycles in the graph)
3. Check for the availability of unit processors and warn on things like being non-public, prerelease (but not marked that way), or not available in any configured catalogs
