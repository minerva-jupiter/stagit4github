    326 ### `/etc/lvm/lvm.conf` Update
    327 続きましては`/etc/lvm/lvm.conf`らしいです。
    328 ```
    329 Configuration file '/etc/lvm/lvm.conf'
    330  ==> Modified (by you or by a script) since installation.
    331  ==> Package distributor has shipped an updated version.
    332    What would you like to do about it ?  Your options are:
    333     Y or I  : install the package maintainer's version
    334     N or O  : keep your currently-installed version
    335       D     : show the differences between the versions
    336       Z     : start a shell to examine the situation
    337  The default action is to keep your current version.
    338 *** lvm.conf (Y/I/N/O/D/Z) [default=N] ? D
    339 --- /etc/lvm/lvm.conf   2025-04-26 20:47:17.070430178 +0900
    340 +++ /etc/lvm/lvm.conf.dpkg-new  2025-08-11 17:46:22.000000000 +0900
    341 ```
    342 こっちはめちゃ長い！
    343 コメントの綴ミスがほとんどだけど、最後にコメントアウトされてない設定が消されてました。
    344 ```
    345 -devices {
    346 -     # added by pve-manager to avoid scanning ZFS zvols and Ceph rbds
    347 -     global_filter=["r|/dev/zd.*|","r|/dev/rbd.*|"]
    348 -}
    349 ```
    350 これはpve-managerが追加したみたいなので、消したくないよー。修正されたオプションや綴ミスだけを取り入れてこの設定だけは残したいところ。
    351 ま、むりなんで元のバーションを残します。こういうときにgitのコンフリクトを込んだ画面みたいにしててくれたら直しやすいのになーって思います。
    352 ということでなんやかんやあって、PVEの更新完了！
