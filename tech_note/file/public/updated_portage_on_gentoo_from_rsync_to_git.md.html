     12 # TL;DR
     13 1. 必要なパッケージを入れる
     14 ```
     15 emerge --ask app-eselect/eselect-repository dev-vcs/git
     16 ```
     17 2. 元あった設定をクリア
     18 ```
     19 eselect repository remove -f gentoo
     20 ```
     21 3. rsync -> git
     22 ```
     23 eselect repository add gentoo git https://github.com/gentoo-mirror/gentoo.git
     24 ```
     25 3.5. もし、途中で引っかかったら、
     26 ```
     27 rm -r /var/db/repos/gentoo
     28 ```
     29 4. 更新
     30 ```
     31 emaint sync -r gentoo
     32 ```
