     12 # What is this article
     13 これは、一人でWindowsを保守できる程度の技量を持ち合わせた人間向けの文章です。
     14 Windows Updateが以下の文言と共に失敗しました。
     15 ```
     16 Install error - 0x800f0983
     17 ```
     18 今回はこれに関して収集した情報を書きます。
     19 # 状況詳細
     20 ```
     21 2025-10 Cumulative Update for Windows 11 Version 24H2 for x64-based Systems (KB5066835) (26100.6899)
     22 ```
     23 install fail with this
     24 ```
     25 Install error - 0x800f0983
     26 ```
     27 - 以前にWindows Updateを停止しませんでした
     28 - 前回の初期化から1年近く経っているので、そろそろ初期化の時期かもしれません
     29 ## device specification

     33 Installed RAM	32.0 GB

     36 ```
     37 # 問題点
     38 [ms QA](https://learn.microsoft.com/en-us/answers/questions/3891780/0x800f0983)
     39 QAの記事にあるように
     40 >エラー コード 0x800f0983 は、コンポーネント ストア (WinSxS) の破損を示します。
     41 
     42 らしいです。
     43 # solution 1 (DISM)
     44 大人しくQAにあるコマンドを実行します。
     45 ```
     46 Dism /Online /Cleanup-Image /StartComponentCleanup
     47 ```
     48 私はtermにalacrittyを使っているのですが、権限昇格とかの機能がないので、sudoを使ったらfileのRL権限がないと怒られました。大人しくalacritty自体をRun as administorします。
     49 なんか59.9%でスタックしてました。長いなぁと思ってたら100%に。やった！って思ったら75%くらいに巻き戻ってゆっくり進み始めました。なんだこりゃ。
     50 ```
     51 Deployment Image Servicing and Management tool
     52 Version: 10.0.26100.5074
     53 
     54 Image Version: 10.0.26100.6584
     55 
     56 [==========================100.0%==========================]
     57 The operation completed successfully.
     58 ```
     59 らしいので、健康にしていきます。
     60 ```
     61 Dism /Online /Cleanup-Image /RestoreHealth
     62 ```
     63 こんどはスムーズ
     64 ```
     65 Deployment Image Servicing and Management tool
     66 Version: 10.0.26100.5074
     67 
     68 Image Version: 10.0.26100.6584
     69 
     70 [==========================100.0%==========================] The restore operation completed successfully.
     71 The operation completed successfully.
     72 ```
     73 再起動します。
     74 `Retry`します。
     75 失敗します。
     76 ま、Dismコマンドでうまくいったことなんて一度も無かったので、そうだよなって感じですね。
     77 # solution 2 (Reinstall windows)
     78 In settiong, System -> Recover -> Reinstall
     79 でボタンをポチッとします。
     80 あとは1.5時間くらい放置です。
     81 壁紙が吹き飛んでましたが、他は設定が変わってるとかはなく、最新の状態になってました。
     82 そういえば、Retryする前に候補に上がっていた25H2は設定のwin update画面からは見えなくなってますね。なんででしょう。
     83 ま、治ったんで良かったです。
     84 # 余談
     85 WinSxSっていうのはWindowsの根幹のコンポーネントが入ってるフォルダーらしいのですが、中身(`C:\Windows\WinSxS\`)dllファイルしか見当たらないし、これをダウンロードし直すだけで良いような気もするんですけどね。Windowsは複雑怪奇。
