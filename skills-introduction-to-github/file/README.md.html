     21 _Get started using GitHub in less than an hour._
     22 
     23 ## Welcome
     24 
     25 People use GitHub to build some of the most advanced technologies in the world. Whether you’re visualizing data or building a new game, there’s a whole community and set of tools on GitHub that can help you do it even better. GitHub Skills’ “Introduction to GitHub” exercise guides you through everything you need to start contributing in less than an hour.
     26 
     27 - **Who is this for**: New developers, new GitHub users, and students.
     28 - **What you'll learn**: We'll introduce repositories, branches, commits, and pull requests.
     29 - **What you'll build**: We'll make a short Markdown file you can use as your [profile README](https://docs.github.com/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme).
     30 - **Prerequisites**: None. This exercise is a great introduction for your first day on GitHub.
     31 - **How long**: This exercise takes less than one hour to complete.
     32 
     33 In this exercise, you will:
     34 
     35 1. Create a branch
     36 2. Commit a file
     37 3. Open a pull request
     38 4. Merge your pull request
     39 
     40 ### How to start this exercise
     41 
     42 1. Right-click **Copy Exercise** and open the link in a new tab.
     43 
     44    <a id="copy-exercise">
     45       <img src="https://img.shields.io/badge/📠_Copy_Exercise-AAA" height="25pt"/>
     46    </a>
     47 
     48 2. In the new tab, most of the prompts will automatically fill in for you.
     49    - For owner, choose your personal account or an organization to host the repository.
     50    - We recommend creating a public repository, as private repositories will [use Actions minutes](https://docs.github.chttps://github.com/minerva-jupiter/skills-introduction-to-github/billing/managing-billing-for-github-actions/about-billing-for-github-actions).
     51    - Scroll down and click the **Create repository** button at the bottom of the form.
     52 
     53 3. After your new repository is created, wait about 20 seconds for the exercise to be prepared and buttons updated. You will continue working from your copy of the exercise.
     54    - The **Copy Exercise** button will deactivate, changing to gray.
     55    - The **Start Exercise** button will activate, changing to green.
     56    - You will likely need to refresh the page.
     57 
     58 4. Click **Start Exercise**. Follow the step-by-step instructions and feedback will be provided as you progress.
