     57 ### 開発環境
     58 パッケージマネージャーはbunを使用しています。
     59 VScodeなりで自分のforkしたリポジトリをコピーして開発してください。
     60 そして、最初にパッケージ一覧をインストールします。```bun install```or```bun i```
     61 プレビューをするために開発鯖を立てます。```bun dev```localhost:3000にアクセスしたらどんなふうな挙動をするかを出してくれます。
     62 何かパッケージを入れたいときは```bun i <packageName>```と入れてください。このへんはnpmとかと変わりません。
