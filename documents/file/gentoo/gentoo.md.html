      1 # Gentoo OSをインストールしてみた
      2 ## まずはインストーラUSBを作る
      3 https://www.gentoo.org/downloads/
      4 から、 Minimal Installation CDのisoをDLする。
      5 DLしたisoをRufusを使って書き込む。
      6 ## LiveUSBを起動
      7 私のPCはUEFIの黎明期に作られたもので、特殊仕様な可能性があったので、LegacyBIOSモードに切り替えて、LiveUSBを起動。

     20 ## パーティショニング
     21 `fdisk /dev/sda`
     22 説明、いらんよね。
     23 
     24 フォーマットしまする。
     25 SSDなので、/dev/sda3は
     26 ```
     27 mkfs.f2fs /dev/sda3
     28 ```
     29 LegacyBIOSでブートするので/dev/sda1は
     30 ```
     31 mkfs.xfs /dev/sda1
     32 ```
     33 スワップは
     34 ```
     35 mkswap /dev/sda2 && swapon /dev/sda2
     36 ```
     37 
     38 んで、マウントする。
     39 事前に
     40 ```
     41 mkdir --parents /mnt/gentoo
     42 ```
     43 しておいて
     44 ```
     45 mount /dev/sda3 /mnt/gentoo
     46 ```
     47 
     48 ## Stageファイル
     49 
     50 `wget`でダウンロードして、
     51 `tar xpvf <stageファイル名> --xattrs-include='*.*' --numeric-owner -C /mnt/gentoo`で展開。
     52 
     53 ## chroot
     54 
     55 chrootの準備。
     56 DNS情報のコピー
     57 ```
     58 cp --dereference /etc/resolv.conf /mnt/gentoo/etc/
     59 ```
     60 ファイルシステムのマウント
     61 ```
     62 mount --types proc /proc /mnt/gentoo/proc && mount --rbind /sys /mnt/gentoo/sys && mount --make-rslave /mnt/gentoo/sys && mount --rbind /dev /mnt/gentoo/dev && mount --make-rslave /mnt/gentoo/dev && mount --bind /run /mnt/gentoo/run && mount --make-slave /mnt/gentoo/run
     63 ```
     64 
     65 んで、chroot
     66 ```
     67 chroot /mnt/gentoo /bin/bash
     68 ```
     69 ```
     70 source /etc/profile
     71 ```
     72 ```
     73 export PS1="(chroot) ${PS1}"
     74 ```
     75

     82 ### portageの設定
     83 
     84 #### スナップショットの更新
     85 `emerge-webrsync`
     86 #### ミラーサーバの選択
     87 ツールをインストール
     88 ```
     89 emerge --verbose --oneshot app-portage/mirrorselect && mirrorselect -i -o >> /etc/portage/make.conf
     90 ```

     92 #### バイナリパッケージホストの追加
     93 ファイル`/etc/portage/binrepos.conf/gentoobinhost.conf`に
     94 ```
     95 [binhost]
     96 priority = 9999
     97 sync-uri = https://distfiles.gentoo.org/releases/<arch>/binpackages/<profile>/x86-64/
     98 ```
     99 と書く
    100 ```
    101 # FEATURES 変数内の値のリストに getbinpkg を追加してください
    102 FEATURES="${FEATURES} getbinpkg"
    103 # 署名を要求する
    104 FEATURES="${FEATURES} binpkg-request-signature"
    105 
    106 ACCEPT_LICENSE="*"
    107 ```
    108 を/etc/portage/make.confに追記
    109 んで、`getuto`でキーリングのセットアップ。

    151 ## ディストリビューションカーネルのインストール
    152 
    153 `emerge sys-kernel/gentoo-kernel-bin`
    154 `-bin`がついているので、ビルドは実行せず、ビルド済のパッケージを引っ張ってくるので、速度が上がる。
    155 
    156 だけれども、logに/etc/portage/make.conf/00video_cardにアップデートが必要って言われました。
    157 これ、ハンドブックの別のページに書いてあるのですが、数回インストールしてますが、毎回聞かれるので、書いとけよとは思います。
    158 `dispatch-conf`これだけでいいです。
    159 これで、無事、インストールが開始します。素晴らしいですね。

    198 `emerge net-misc/dhcpcd`
